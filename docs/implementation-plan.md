# 「钱去哪里了」MVP 实施计划

## 目标与范围

V1.0 是可真实记账的离线小工具：用户不注册、不绑定支付账户，账单默认保存在小红书容器提供的本地存储中。核心闭环为「记录 → 分析 → 控制 → 存钱」。当前视觉使用主题紫 `#4037BD`、浅紫页面底色、大字金额和统一白色卡片；顶部使用小尺寸 IP 图标做品牌识别，避免在内容区重复堆放 Logo；品牌口号为「钱去哪里了？记下来就知道了。」

本版包含首页、记账、统计、我的四个底部入口；手动和语音转写辅助录入；账单新增、查看、修改、删除；月度与分类统计；月度和分类预算；多个存钱目标；数据导出、备份、恢复与清空。账单金额用整数分保存，不接入支付、银行卡、账号或云端账本。

## 实施顺序

1. **按已提供的当前官方口令确认规范**：读取已安装的 1.11.1 Skill、全部相关 references，并对照当前在线文档核验容器 API、系统与 WebView 基线、可用文件交换方式。
2. **搭建真实页面状态**：把现有四个演示视图调整为首页、记账、统计、我的；移除硬编码统计与虚构总结；所有金额、账单数和图表都由账本计算。首次打开显示空状态。
3. **完成账单闭环**：配置指定收入与支出分类；支持收入/支出、金额、分类、日期、备注；金额校验为正数并转换为分；新增、编辑、详情、二次确认删除；保存期间禁用重复提交；按日期、月份筛选。
4. **接入本地持久化与迁移**：优先使用文档确认支持的 `window.xhs.miniTool` Storage API；启动时检测 `window.xhs`、`miniTool`、方法和客户端版本。版本未知、低版本、缺方法或写入失败时明确提示，不能假装保存成功，也不能静默回退浏览器存储。对旧数据按版本读取、校验、迁移、读回确认；迁移失败保留原数据。
5. **实现月度统计和预算**：按账单日期计算月收入、支出、结余、今日支出、每日支出、分类占比、排行和历史月份对比；预算仅计支出，支持总预算与分类预算、剩余金额和温和提醒。
6. **实现语音辅助记账**：只在用户主动点击后检测 `SpeechRecognition` / `webkitSpeechRecognition`。没有能力时提示使用手机键盘语音输入或手动输入。识别文本解析金额、类型、分类、日期、备注和原文；多金额、日期含糊或信息不足时标记待补全。结果始终先进入确认区，确认后才写账；取消不留记录。应用不调用自建/第三方语音接口；宿主 Web Speech 的传输与处理方式取决于客户端，官方文档未保证完全本地处理，不对其作此承诺。
7. **实现存钱目标与数据管理**：存钱目标包含名称、目标金额、目标日期、累计金额与版本；支持多个目标和进度。CSV/JSON 导出、JSON 恢复、格式校验、恢复前备份提醒、清空账本二次确认、隐私与关于页面。
8. **验证、审计和打包**：覆盖金额分计算、日期归属、分类/月度统计、持久化、迁移、失败提示、语音确认/取消、预算、目标、导出/恢复、重复点击和响应式布局；执行口令指定的全部官方校验与修复；干净构建后审计目录和 ZIP，确认入口在 ZIP 根目录。分别记录普通浏览器、官方模拟器和真机证据，不混为一谈。

## 数据模型

```js
{
  id: "bill_xxx",
  type: "expense", // expense | income
  amount: 3500,     // 整数分
  category: "餐饮",
  date: "2026-11-19",
  note: "午餐",
  source: "manual", // manual | voice
  createdAt: 0,
  updatedAt: 0
}
```

每个数据分片带 `schemaVersion`。账单按月份分片，必要时继续拆成有序小片，避免把无限增长账本放入单个 Storage Key；预算按月份保存，目标单独保存，元信息记录当前 schema 与已迁移状态。调用 `getStorageInfo` 监控总容量。当前在线文档的 Storage 下限为客户端 9.46.0，单 Key 1 MB、工具总量 10 MB；最终以口令 Skill 和在线文档核实结果为准。

写入采用「先校验、再持久化、成功后更新页面状态」；异常时保留用户输入并显示未保存提示。更新、删除只触及目标月份分片。迁移可重试，不覆盖较新的目标数据。

预算示例：

```js
{
  month: "2026-11",
  totalBudget: 500000,
  categoryBudgets: { "餐饮": 150000, "交通": 50000 }
}
```

存钱目标示例：

```js
{
  id: "goal_xxx",
  name: "旅行基金",
  targetAmount: 1000000,
  savedAmount: 120000,
  targetDate: "2027-06-01",
  createdAt: 0,
  updatedAt: 0
}
```

## 页面与代码边界

- `index.html`：单页入口，保留无 JS 时可辨识的首屏；本地经典脚本和样式。
- `app.js`：四页导航、渲染、表单交互与无障碍状态。
- `styles.css`：Chrome 61 基础样式、能力增强和移动安全区回退。
- 新模块只在现有原生 HTML/CSS/JS 不够用时拆分；不引入未经官方 Skill 验证的框架或依赖。
- 每个账单、预算、目标的展示都由真实本地数据驱动，空账本不注入演示账单。

## 官方能力约束与待核实项

- 在线能力文档当前未列出平台语音转文字 API；Web Speech 只作为逐方法能力检测后的增强，不把识别当成已保存。其内部音频处理方式未由官方能力文档保证；需要严格避免设备外处理时使用手动输入。
- 小工具容器禁用网页网络请求、`navigator.clipboard`、`<a download>`、Blob 下载、`eval`、`new Function`、WebAssembly、iframe/object 和外部资源。文本可由用户手动选择复制。
- 当前公开能力说明没有确认通用 CSV/JSON 文件下载或任意文件导入选择器。`<input type="file">` 的平台选择器仅支持图片和视频。若最新上传口令/官方文档没有额外公开的文件交换能力，导出与恢复采用可选择文本/手动粘贴，并清楚提示其限制；不把私有 `userDataPath` 文件冒称为用户已下载的备份文件。
- 容器 Storage 与文件系统不是永久备份。卸载、清理或环境变化可能丢失数据；在隐私页和备份流程提示定期备份。
- 在线文档显示系统支持门槛为 Android 10+ / iOS 18.4+，Android WebView 目标仍为 Chrome 61；需在口令对应 Skill 中再次确认。

## 验收清单

- 空账本；手动收入/支出；金额边界；编辑、详情、删除确认；日期与月份切换。
- 本月收入、支出、结余、今日支出、每日趋势、分类统计、历史月份对比均与真实账单一致。
- 月度/分类预算只计算支出；预算接近和超额状态正确；多个存钱目标进度正确。
- 有/无语音识别能力；含单一金额与日期的文本解析；模糊、多金额、缺字段；确认写入与取消不保存。
- Storage 读写、删除失败提示；超容量处理；版本迁移成功、失败与重试；快速重复点击只产生一笔。
- JSON 校验、备份提示、恢复与 CSV/JSON 导出路径；清空账本二次确认。
- 多种手机宽度、软键盘和安全区；Chrome 61 语法/CSS 检查；静态资源离线且 ZIP 根目录直接含 `index.html`。
