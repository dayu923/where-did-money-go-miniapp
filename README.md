# 钱去哪里了

「钱去哪里了？记下来就知道了。」是一款年轻、轻松的离线小红书小工具 MVP。品牌主色为 `#4037BD`，顶部用小尺寸 IP 图标配品牌名，首页不再重复摆放 Logo；内容用明快标题、轻松文案和统一白色卡片呈现。账单金额以整数分存储；账单、月预算、分类预算和存钱目标由用户实际录入，不再注入演示数据。

## 运行与验证

项目不依赖运行时外部库。图标使用 Lucide Static 1.77.0 的按需 SVG 文件，随包离线加载；不引入图标脚本或 CDN。

可在本地用静态服务器查看页面壳：

```sh
python3 -m http.server 8000
```

浏览器预览没有小红书 Storage，不会保存真实账单；真实记账必须在注入 `window.xhs.miniTool` 且客户端版本满足要求的小红书小工具容器内完成。按平台版本检测通过后使用容器 Storage；缺失、低版本或调用失败时会显示错误，不回退到 `localStorage`。

运行代码自检：

```sh
node tests/core.test.js
node tests/storage.test.js
```

## 功能

- 首页收支、结余、预算与最近账单；点收支卡片可筛选账单。
- 手动新增、查看、修改和二次确认删除账单。
- 检测 Web Speech API 的可选语音增强；识别结果必须手动检查确认。容器不支持或启动失败时，聚焦输入框并提示使用手机键盘语音输入或手动输入。
- 月度收支、日支出趋势、分类统计和上月对比，均从用户数据计算。
- 月预算、分类预算、存钱目标。
- CSV 文本导出、JSON 备份与校验恢复、清空账本。
- 账单按月份分片；本地账本支持 schema 迁移和失败保护。

## 目录

- `index.html`：离线小工具入口和静态首屏。
- `styles.css`：大鱼紫色、轻松贴纸感的响应式界面。
- `assets/brand/logo-mark.png`：顶部品牌区使用的本地 IP 图标；其余品牌素材保留在源码中。
- `assets/icons/`：本地 Lucide SVG 图标；版本与许可证文本见 `license.json`。
- `app.js`：导航、渲染、交互、语音草稿及数据管理。
- `core.js`：金额、账单、统计、语音文本解析和数据校验。
- `storage.js`：版本检测、分片存储、数据迁移和写入保护。
- `tests/`：核心与模拟容器 Storage 自检。
- `docs/implementation-plan.md`：产品与技术实施计划、验收状态。
- `dist/mvp/`：从项目源码整理的离线交付目录。
- `artifacts/qian-qu-na-le-v1.0-ui-refresh.zip`：按 Skill 规则生成的当前 UI ZIP。

## 数据与隐私限制

页面代码不接入自建或第三方网络服务，不上传账单，不接入银行卡、支付账户或账号。Web Speech API 由运行容器实现，官方文档未承诺其识别过程是否完全本地处理；若不接受这一点，可使用手动输入。平台本地存储可能因卸载、清理或客户端环境变化而丢失；请定期在「我的」中导出 JSON 并自行妥善保存。容器禁止下载和剪贴板 API，因此导出内容需手动选择复制，恢复时手动粘贴。

## 尚待平台验证

源码和 ZIP 已通过当前 Skill 的静态审计及 Node 自检；这不代表审核通过或真机兼容。还需在创服平台模拟器验证 Storage 接口、记账全流程和页面表现，并在 Android / iOS 真机扫码验证同一 ZIP。普通浏览器预览不能代替这些检查。
